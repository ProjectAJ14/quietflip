# timekeeping

Pure-Dart countdown state machine (`Countdown`), the pomodoro focus/break
sequence (`Pomodoro`: 25 min focus, 5 min break, numbered rounds) and formatting helpers
(`formatClock`, `formatHms`, `ceilToSecond`, `formatStopwatch`) for QuietFlip.
No Flutter, no I/O. See `CLAUDE.md` for the API contract.
